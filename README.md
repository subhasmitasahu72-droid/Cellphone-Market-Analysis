# Cellphone Market Analysis (Python & Tableau)

## 📌 Project Overview
This project performs an end-to-end analysis of the cellphone market using Python and Tableau.
The goal is to understand pricing behavior, feature impact, and market structure across brands
and operating systems.

## 🧠 Objectives
- Analyze cellphone pricing patterns
- Identify key price-driving features such as RAM, camera, and battery
- Study brand positioning and market dominance
- Visualize insights using interactive Tableau dashboards and storyboard

## 🛠 Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn, SciPy)
- Tableau Public
- GitHub

## 📊 Dashboards
### Dashboard 1 – Market Overview & Price Drivers
- Price distribution analysis
- Brand-wise average pricing
- Feature impact on pricing

### Dashboard 2 – Market Structure & Strategic Insights
- Market share by brand
- High-end phone Pareto analysis
- OS vs Brand distribution
- Price trends and outlier detection

## 📁 Repository Structure
- data/ → Dataset
- notebooks/ → Python analysis
- tableau/ → Tableau dashboards & storyboard
- screenshots/ → Dashboard images

## 📈 Key Insights
- The cellphone market is highly segmented across price ranges
- RAM strongly influences pricing, followed by camera quality
- Battery capacity has limited impact on premium pricing
- Android dominates the market, while iOS remains exclusive to Apple
